# One-command installation

SciAgentKit is designed so a new GitHub user can install and prepare the project with one command.

## Recommended local install

After cloning the repository:

```bash
bash scripts/install.sh --full --agents --external
```

This command:

1. creates or updates a `sciagentkit` conda environment when conda is available;
2. falls back to a local `.venv` if conda is unavailable;
3. installs SciAgentKit in editable mode;
4. installs core scientific dependencies;
5. optionally installs OpenBabel, AutoDock Vina, and fpocket via conda-forge;
6. generates `AGENTS.md`, `CLAUDE.md`, Cursor rules, and MCP config fragments;
7. runs `sciagent doctor`;
8. runs the test suite;
9. runs the bundled demo.

## Minimal install

```bash
bash scripts/install.sh --core --agents
```

Use this for molecule-library audit only.

## Developer install

```bash
bash scripts/install.sh --dev --agents --external
```

## Remote install from GitHub

After publishing the repository, edit `scripts/install_from_github.sh` and replace:

```text
https://github.com/ehsansyh/sciagentkit-drug-discovery-skills.git
```

Then users can run:

```bash
curl -fsSL https://raw.githubusercontent.com/ehsansyh/sciagentkit-drug-discovery-skills/main/scripts/install_from_github.sh | bash -s -- --full --agents --external
```

Or without editing the file:

```bash
SCIAGENTKIT_REPO=https://github.com/ehsansyh/sciagentkit-drug-discovery-skills.git \
  curl -fsSL https://raw.githubusercontent.com/ehsansyh/sciagentkit-drug-discovery-skills/main/scripts/install_from_github.sh | bash -s -- --full --agents --external
```

## Docker install

```bash
docker compose up --build sciagentkit
```

For MCP server mode:

```bash
docker compose up --build sciagentkit-mcp
```

## Health check

```bash
sciagent doctor
```

## Activate environment

After installation:

```bash
source scripts/activate.sh
```

or manually:

```bash
conda activate sciagentkit
```

## Agent/MCP files generated by `--agents`

```text
AGENTS.md
CLAUDE.md
.cursor/rules/sciagentkit.mdc
.mcp/sciagentkit.json
claude_desktop_config.fragment.json
codex_config.fragment.toml
```

These are templates. Some clients still require copying the fragment into their own application config because agent runtimes use different configuration formats.
