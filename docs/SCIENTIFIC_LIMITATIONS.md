# Scientific Limitations

SciAgentKit is a workflow and audit toolkit. It is not a biological oracle.

## Current implemented outputs

- canonical SMILES validity
- duplicates and exact novelty
- RDKit descriptors
- Bemis-Murcko scaffold diversity
- property figures
- reproducibility manifests

## What these do not prove

- biological activity
- binding affinity
- selectivity
- ADMET safety
- clinical relevance
- novelty in patent space

## Required caution

Use SciAgentKit outputs as auditable computational evidence, not as final experimental truth. Docking, MD, QSAR, and wet-lab validation each have distinct assumptions and failure modes.
